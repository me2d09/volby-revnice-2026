- Čísla v tabulkách a jména kandidátů jsou veřejné volební údaje, ale uveď původ a ověř podmínky opětovného využití výsledků ČSÚ.
- Okrsková mapka `data/raw/okrsky_reference_map.png` pochází od uživatele, práva ke sdílení nejsou známá: do veřejného GitHubu raději nezařazovat bez ověření licence. Je jen volitelný vizuální podklad.

- Interaktivní Plotly HTML zveřejnit jako soubory nebo na GitHub Pages; na GitHubu v `.ipynb` mít i statický fallback.
- Nezahrnovat osobní či účetní data lidí nad rámec již zveřejněných veřejných kandidátních záznamů.
